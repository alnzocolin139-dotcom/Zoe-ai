# ZOE AI — الإصدار الأول

## ما الذي يعمل الآن؟
- واجهة عربية متجاوبة مناسبة للآيفون.
- محادثة تجريبية محلية (ليست ذكاءً اصطناعياً بعد).
- ذاكرة يدوية محفوظة في `localStorage` على نفس المتصفح والجهاز.
- ملف PWA وإمكانية الإضافة إلى الشاشة الرئيسية بعد النشر على HTTPS.
- تخزين مؤقت أساسي لبعض ملفات التطبيق.

## تنبيه مهم
هذه النسخة لا تتصل بأي نموذج ذكاء اصطناعي ولا ترسل البيانات إلى خادم. الردود الحالية تجريبية فقط. لا تضع كلمات مرور أو معلومات شديدة الحساسية في الذاكرة. مسح بيانات Safari أو تغيير المتصفح/الجهاز قد يؤدي إلى فقدان الذاكرة المحلية. أضفنا خيار حذف الذكريات.

## تشغيلها مجاناً عبر GitHub Pages
1. افتح https://github.com/ في Safari وأنشئ حساباً أو سجّل الدخول.
2. أنشئ مستودعاً جديداً باسم `zoe-ai` واجعله Public.
3. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على مجلد `icons`.
4. من المستودع افتح Settings ثم Pages.
5. في Build and deployment اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages. قد يستغرق النشر بضع دقائق.
7. افتح الرابط في Safari على الآيفون.
8. اضغط زر المشاركة، ثم Add to Home Screen، ثم Add.

## ملاحظات الآيفون
- استخدم Safari لإضافة التطبيق إلى الشاشة الرئيسية.
- التطبيق يحتاج الإنترنت أول مرة لتحميله؛ التخزين المؤقت يساعد على فتح الواجهة لاحقاً دون اتصال، لكن وظائف الذكاء الاصطناعي غير موجودة بعد.
- بيانات الذاكرة محفوظة محلياً في بيانات موقع Safari، وليست مزامنة بين الأجهزة.

## المرحلة التالية
ربط التطبيق بنموذج لغوي عبر خادم وسيط آمن. لا تضع API key داخل `app.js` أو أي ملف يصل إلى المتصفح؛ يجب حفظ المفتاح في متغيرات بيئة على الخادم. قد تتطلب واجهات النماذج المدفوعة وسيلة دفع حتى لو كانت الواجهة مجانية.
